# Experiment 2 – Azure Synapse Dedicated SQL Pool

## Aim
To create an Azure Synapse dedicated SQL pool and load data for analysis.

## Theory
Azure Synapse Analytics is a cloud analytics service used to analyze large amounts of data. A dedicated SQL pool provides a scalable environment for storing and querying structured data.

## Flow
Azure Synapse Workspace → Dedicated SQL Pool → Load Data → Query Data

## Procedure
1. Open Azure Synapse Workspace.
2. Create a dedicated SQL pool.
3. Configure the required performance settings.
4. Create the SQL pool.
5. Load data into the SQL pool.
6. Run SQL queries to analyze the data.

## Expected Output
The dedicated SQL pool is successfully created and data can be loaded and queried.

## Result
Thus, an Azure Synapse dedicated SQL pool was successfully created and configured for data analysis.
